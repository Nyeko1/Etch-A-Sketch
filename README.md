# 🎨 Etch-A-Sketch

This is a simple browser-based **Etch-A-Sketch** drawing app built using **HTML**, **CSS**, and **JavaScript**. You can draw by hovering your mouse over the grid cells. The grid resolution is adjustable using a slider, giving you a pixel-art-like drawing experience.

![etch-a-sketch-demo](./screenshot.png) <!-- Optional: replace with actual screenshot path -->

---

## 🌟 Features

- 🖱️ Draw by hovering over the squares
- 🎚️ Adjustable grid resolution using a range slider (1x1 to 100x100)
- 🧼 Automatically resets and redraws the grid on slider change
- 📐 Responsive, centered layout with Flexbox
- 🧱 Cells snap into perfect squares, styled with soft borders

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox layout, slider styling)
- Vanilla JavaScript (DOM manipulation)

## 📷 Usage Instructions
-Hover over the grid cells to draw.

-Use the slider below the grid to adjust the number of squares per side.

-The resolution label will update in real-time (e.g. 16 x 16 (Resolution)).

-The grid will regenerate every time you change the slider value.
